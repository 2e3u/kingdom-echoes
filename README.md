# KingdomEchoes

A Godot 4.6 sandbox RPG prototype.

## Project

- Engine: Godot 4.6
- Main scene: `scenes/main_menu.tscn`
- Gameplay scripts: `scripts/game/`
- Shared/server scripts: `scripts/shared/`, `scripts/server/`
- Assets: `assets/`
- Tests and probes: `tests/`

## Notes

Generated Godot cache files such as `.godot/` are ignored. Open the project by importing this folder in Godot.
