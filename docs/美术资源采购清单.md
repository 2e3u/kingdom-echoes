# KingdomEchoes 美术资源采购清单

> **目的**：解决"画风不统一"——用一套（或几套同风格）完整素材包，替换掉东拼西凑的素材。
> **铁律**：优先「同一作者 + 带过渡块 + 统一分辨率」。宁可少买，绝不混风格。

---

## 0. 先定死的统一规格（所有素材必须一致）

| 项 | 选定 |
|---|---|
| 视角 | **俯视 top-down**（不是等距 isometric） |
| 像素分辨率 | **32×32**（建议；细节足、比 16×16 耐看。全程只用这一个尺寸） |
| 风格基调 | 选定后不再混：描边(有/无)、色调(明亮/灰暗)、饱和度 |
| 授权 | **允许商用**（CC0 或付费商用授权，避免以后返工） |

> 注：你代码里 `TILE_SIZE=64` 是世界单位，和素材像素分辨率是两回事。素材常见 16/32，渲染时放大即可。

## 1. 品类需求（⭐ 越多越优先）

### ⭐⭐⭐ 地形 Tileset —— 地图好看的命根子
- [ ] 基础地表：草地 / 泥土 / 沙地 / 雪地 / 石地
- [ ] **过渡块 (autotile)**：草↔沙、草↔水、草↔泥 的接边块 —— **没有这个 = 继续锯齿，必须有！**
- [ ] 水：水面 / 海岸线 / 河流
- [ ] 路：泥路 / 石板路
- [ ] （可选）悬崖、坡 —— 想要立体感才需要

### ⭐⭐⭐ 植被装饰
- [ ] 树：阔叶 / 针叶（各多个变体）
- [ ] 灌木 / 草丛 / 花 / 蘑菇
- [ ] 石头 / 枯木 / 树桩

### ⭐⭐ 资源矿物
- [ ] 矿石节点：铜 / 铁 / 石 / 金
- [ ] 可采集资源

### ⭐⭐ 角色
- [ ] 玩家：4 方向行走（最好 + 待机 / 采集 / 攻击）
- [ ] （可选）敌人 / NPC / 动物
- 注：现在的骑士和整体不统一，建议跟着新包一起换掉

### ⭐⭐ 建筑 / 建造
- [ ] 建造件：墙 / 地板 / 门 / 围栏
- [ ] 功能站：工作台 / 熔炉 / 铁砧 / 箱子

### ⭐ 物品图标
- [ ] 材料 / 工具 / 武器 / 防具 / 消耗品 的 icon

### ⭐ UI（已有羊皮纸，可不换）
- [ ] （锦上添花）统一的按钮 / 面板 / 槽位 / 血条

### 地标（想要"罗马拓荒录"那种结构感才需要）
- [ ] 火山 / 熔岩
- [ ] 营地 / 遗迹（POI）

---

## 2. 挑选避坑 checklist

- [ ] **同一作者 / 同一系列**（统一的根本）
- [ ] 地形带 **autotile 过渡块**（看示例图：交界处是自然过渡，不是硬色块拼接）
- [ ] 分辨率统一（别混 16 和 32）
- [ ] 看示例图：交界自然、色调和谐
- [ ] 授权清楚（CC0 / 商用 / 署名即可）
- [ ] 一个包覆盖品类越多越好（少跨包 = 越统一）

---

## 3. 去哪找

- **itch.io**（首选，独立素材最全）
  - 搜索词：`top down rpg tileset`、`pixel art rpg asset pack`、`32x32 overworld tileset`、`farming rpg tileset`
- CraftPix / GameDev Market / OpenGameArt（后者多 CC0 免费）
- **可参照风格的知名系列**（⚠️ 自己核实风格 & 授权，不一定适合你）：
  - Sprout Lands（可爱农场风）
  - Cute Fantasy RPG
  - Tiny Swords（中世纪）
  - Mana Seed（角色动画体系）
  > 这些只是"大概长这样"的参照，重点看是否符合**中世纪奇幻**调性 + **带过渡块**。

---

## 4. 现实采购策略（别一次买全）

1. **第一步只搞「地形(带过渡) + 植被」** —— 这是地图好看的 80%，先把这个换了，地图立刻上档次
2. 角色、建筑、物品、UI 分批补
3. 全程守住"第 0 节统一规格"，宁可少买，不混风格

---

## 5. 买回来之后（接入要点，给开发参考）

- 地形过渡块 → 在 Godot 里配 **TileMap + Terrain（autotile）**，替换当前"程序贴图色块"
- 这一步能在**现有无限 chunk 架构上做**，不必推翻世界生成
- 植被/资源 → 接到现有 `resource_defs` / `decoration_defs`（poisson 候选点系统不动，只换贴图）
- 角色 → 替换 `knight_aligned.png`，按新包的帧规格重配 `player.tscn` 动画
